## Integration with Using-SuperPowers

### How It Works

1. **Activation:** Skill `using-superpowers` is triggered at session start
2. **Detection:** Analyzes user request for keywords matching skill patterns
3. **Routing:** Suggests or auto-invokes appropriate skill from the 35+ available
4. **Execution:** Skill SKILL.md file is loaded and followed

### Pattern Matching

When you mention these patterns, the system automatically detects relevant skills:

```
Pattern              → Detected Skills
"GitHub"             → github-code-review, github-workflow-automation, github-release-management
"vector search"      → agentdb-vector-search, agentdb-advanced
"multi-agent"        → flow-nexus-platform, swarm-orchestration, hive-mind-advanced
"architecture"       → v3-ddd-architecture, v3-core-implementation, sparc-methodology
"performance"        → v3-performance-optimization, performance-analysis
"memory"             → v3-memory-unification, agentdb-memory-patterns
"CI/CD"              → github-workflow-automation, github-release-management
"learning"           → agentdb-learning, reasoningbank-agentdb, agentdb-memory-patterns
```
