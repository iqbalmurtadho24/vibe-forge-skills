## 🔧 THE THREE LAYERS EXPLAINED

### Layer 1: CODE UNDERSTANDING (Codebase-Memory)
**What it does**: Understands your codebase as a graph

- 📊 Code architecture visualization
- 🔍 Searches code graph (not files)
- 📈 Impact analysis
- 🧩 Dead code detection
- 🔗 Call chain tracing
- 158 languages supported

**3 Agent Modes**:
- 🚀 **Scout** (fast lookups): <2 seconds
- 📊 **Default** (full analysis): 5-10 seconds
- 🔍 **Auditor** (code quality): 10-30 seconds

### Layer 2: SKILL ORCHESTRATION (using-superpowers)
**What it does**: Routes to the right skill automatically

- 48 professional skills
- Auto-triggers based on keywords
- Smart tool routing
- Context preservation
- 76+ CLI tool support

**Skill Categories**:
- Development (14): planning, coding, debugging
- Security (4): pentesting, vulnerability fixes
- Code Quality (7): simplification, review
- Design (8): UI/UX, tokens, systems
- Browser (5): automation, testing
- Efficiency (7): token savings, compression

### Layer 3: CONTEXT COMPRESSION (Headroom)
**What it does**: Reduces token usage while preserving context

- 60-95% token savings for JSON
- 15-20% token savings for code
- Smart content routing
- Reversible compression (cache originals)
- Cross-agent memory sharing
- Auto-learns from failures

**Compression Types**:
- SmartCrusher: JSON structures
- CodeCompressor: AST-based code
- Kompress-v2: ML-based text compression
